Frequently asked questions

Everything you need to know about making your site readable for AI agents.

What is an llms.txt file?

llms.txt is an emerging standard - think robots.txt, but for AI. It's a Markdown index that tells AI agents like ChatGPT, Claude and Perplexity what your site is about and points them to your most important pages, so they can read and cite you accurately. Agent-Native generates it (plus llms-full.txt) for you automatically.

How does Agent-Native make my website readable for AI agents?

When a known AI agent requests a page, Agent-Native serves a clean, structured version of the same content - semantic HTML with JSON-LD and a Markdown version - without the navigation, scripts and layout clutter a model discards anyway. Your human visitors keep seeing your normal design.

Is this cloaking? Will it hurt my SEO?

No. The agent version shows the same content as your original page, just in a machine-readable format, and the canonical tag always points back to the human-readable URL. It's a faithful representation of your content, not a shadow page built to manipulate rankings.

Do I need WordPress to use Agent-Native?

No. There are two ways to use it: a WordPress plugin that detects agents at request time and serves the structured version dynamically, or a browser-based web tool for static sites - upload your site's ZIP and get back an agent-native version plus the server configuration. Your files never leave your browser.

Which AI agents and crawlers are supported?

Agent-Native detects common AI crawlers such as ChatGPT (GPTBot), Claude (ClaudeBot), Perplexity and other LLM agents by their user agent. Detection is a best-effort approach - user agents can be spoofed - but it covers the major agents that read the web today.
